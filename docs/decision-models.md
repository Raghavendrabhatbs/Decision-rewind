# Decision Models

The workbench trains five classifiers on a generated 20,000-record synthetic
training dataset. Their targets are deterministic labels generated by the
project's simulation rules, not independent real-world ground truth. Each
classifier uses a deterministic, stratified 80/20 train/validation split and
is fitted once per model version.

| Decision | Algorithm | Input features |
|---|---|---|
| D1 – Authentication | Logistic Regression | Failed logins, login hour, geo anomaly, source IP trust |
| D2 – Threat Severity | Random Forest | Failed logins, threat score, previous alerts |
| D3 – Asset Protection | Decision Tree | Asset criticality, threat score, previous alerts |
| D4 – Incident Escalation | Logistic Regression | Threat score, geo anomaly, asset criticality, D2 severity |
| D5 – Response Action | Random Forest | D2 severity, asset criticality, geo anomaly, failed logins |

Training and validation loss and accuracy are recorded for each fit. Model
metadata and a SHA-256 checksum are persisted alongside the versioned model
artifact. A separate evaluation command reports held-out accuracy, weighted
precision, recall, F1, and confusion matrices:

```powershell
py -3.11 -m backend.app.ml.train
```

Counterfactual replay uses the exact model artifact pinned to an experiment.
It does not fit or update a model. D2 is evaluated before D4 and D5 because
those classifiers consume the D2 severity output. Persisted state and
deterministic rewind verification remain authoritative.

## Precinct6 source experiments

The real-world source is the `signals` split of WitFoo Precinct6 v2.1.0 at
revision `96311c2e29611d8ddbf1c0d59f531f6a362b8233`. It supplies 38 source
columns and an automated `label_binary` class (`benign`, `suspicious`, or
`malicious`), but the dataset card explicitly says there is no independent
analyst-verified ground truth. Those labels are preserved as source evidence
and are not mapped onto any of D1–D5.

For a Precinct6 experiment, the original source record and label remain
immutable. Existing D1–D5 classifiers are applied only to their established
decision features. Features not supplied by Precinct6 (such as failed-login
counts, geo anomaly, asset criticality, and previous-alert counts) are
deterministically populated from the experiment seed and source ID, and each
feature is marked `simulated`; unavailable source values are not represented
as measured data. The outputs therefore test the rewind architecture under
explicitly simulated decision context and must not be interpreted as actual
Precinct6 decisions, supervised metrics, or operational recommendations.

Import is explicit and revision-pinned. The importer validates the file SHA-256,
column schema, and every row while indexing bounded batches. A Precinct6
experiment reserves 200 previously unused source IDs transactionally; if
fewer than 200 remain, it fails instead of creating a partial or synthetic
substitute. The dataset revision, source IDs, mapping version, simulation seed,
and frozen model version are persisted for replay.
